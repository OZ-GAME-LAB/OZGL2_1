좌표와 연결 규약
- 바닥 및 경계: 32x32, 32 PPU, 셀당 1x1 월드 유닛을 기본으로 함.
- 장식: 32 PPU. 시체·뼈 2x2, 막사 3x2.5, 보급품 1x1 월드 유닛. 실제 그림 크기는 투명 여백을 제외하면 더 작음.
- Sprite Single / Full Rect / Point / Clamp / mipmap 없음 / 무압축 / sRGB. camp_approach 아틀라스만 Sprite Multiple.
- mask = N(1) + E(2) + S(4) + W(8). 해당 방향에 같은 지형이 이어지면 비트를 설정.
- N은 이미지 위쪽이며 Unity 그리드 좌표 (0,+1), E=(+1,0), S=(0,-1), W=(-1,0).
- 예: m00=고립된 칸, m05=남북 연결, m10=동서 연결, m15=네 방향 내부.
- 용사 진입부는 최대 배치 그리드 위쪽에만 표시. 같은 잔디 바탕을 유지하고 투명한 마른 흙·풀 흔적을 별도 레이어로 덧그림. 이동 경로나 충돌 규칙과 무관함.
- 오염 경계는 먼저 그린 흙/잔디 경계 위에 별도 레이어로 표시할 것. 기본 흙을 오염 스프라이트 하나로 대체하면 투명 부분이 잔디로 보일 수 있음.
- 흙 경계 아래에도 전체 배경 잔디가 있어야 함. InGame의 OutdoorBattlefieldPresentation(-200) 위에 흙(-100), 오염(-99)을 겹쳐 표시함. 잔디를 경계 PNG에 다시 넣지 않아야 미확장 영역과 같은 바탕이 이어짐.
- 셀별 변형은 좌표 기준으로 고정 선택하여 카메라 이동이나 배치 갱신 때 무늬가 바뀌지 않도록 할 것.
- 이 세트는 4방향 경계 16종이며, 대각선까지 구별하는 47종 RuleTile 세트는 아님. 대각선 접점은 작은 둥근 여백이 남는 자연 지면 표현임.
- 배치 칸 안내선, 점유/불가/호버 표시는 PNG에 굽지 않았음. 기존 준비 표시 레이어에서 별도로 그릴 것.
- 장식은 최대 배치 범위, 마왕의 중앙 하단 자리, 용사 주 이동 경로를 피해서 배치할 것.

공유/사용
- 신규 자체 제작 아트는 AGENTS.md에 따라 Assets/_Project/Art 아래 저장. 기존 98.ExternalAssets의 석재 샘플은 이동·삭제하지 않음.
- PNG와 Unity가 생성한 .meta를 함께 관리. 기존 GUID 임의 재생성 금지.
- scene이나 runtime 연결 코드에 output/ 경로를 참조하지 않을 것.
- tile_manifest.json은 파일 목록과 연결 규약을 설명하는 제작 메타데이터. 런타임은 SO 참조와 GridTerrainPattern을 사용함.

현재 단계의 확인 범위

- 모든 난이도 완주, 재도전, 개별 화면비의 시각 검수는 이번 검증에 포함하지 않음.

전진 기지 설정
- 중앙 막사 (3.5, 8.6), 왼쪽 상자 (1.2, 7.85), 오른쪽 통·장작 (5.9, 7.65). 위치 단위는 그리드 셀.
- 기존 세 스폰 지점 (0.5, 6.5), (3.5, 6.5), (6.5, 6.5)를 유지하고 장식은 그 뒤에 배치함.
- 장식은 Collider 없이 SpriteRenderer로만 생성하며 배치/확장 규칙에 관여하지 않음.
- 크기와 위치는 외형 SO에서 조절. 최대 배치 영역과 겹치는 장식은 생성 시 제외됨.
- 흔적은 원점 (0,5), 가로 8칸, 세로 5칸의 고정 장식 타일. 배열은 왼쪽 아래부터 오른쪽으로, 다음 행은 위쪽으로 연결.
- 원화 전체를 먼저 축소·공통 팔레트로 변환한 뒤 Sprite를 나누므로 경계에서 무늬가 끊기지 않음. 투명 알파를 보존하고 잔디와 별도로 렌더링함.
- Approach Opacity로 길의 강도를 조절할 수 있음. 흙 확장 영역처럼 꽉 찬 바닥으로 보이지 않게 설정함.
- 막사는 전투 카메라에서 보임. 준비 카메라는 배치 영역을 확대하므로 막사가 화면 밖에 있을 수 있음.
- 새 장식 원화는 내장 image_gen으로 생성하고 투명도를 유지한 채 픽셀 크기에 맞춰 분리·축소함.

- InGame 전용 설정에 연결했으며 InGame_2의 별도 배경에는 자동 적용되지 않음.

준비 가독성과 시체 장식 조정 / 2026-10-03
