# Lobby Collections v1 — 생성 기록

내장 image_gen 사용. 도감 카드, 업적 카드, 진영 아이콘 2종, 잠금 아이콘을 각각 생성했다.
글자는 이미지에 넣지 않고 TMP로 배치한다. 생성 원본은 Sources/LobbyCollections_v1에 보존한다.
사용자 승인 후 알파 경계 crop·여백·크기 정렬만 수행한다. 실제 유닛 초상은 Unity 모델을 렌더한다.
