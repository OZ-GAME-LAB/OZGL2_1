## 구현 전 확인

- 현재 `UI_Battle_MutedPreview`의 트래커는 우측에 있다. 이번 시안은 요청사항에 맞춰 좌측 트래커/우측 확장으로 제작했다.
- 기존 `Canvas_Popups/Popup_Synergy`는 클릭형 모달이므로 호버 툴팁으로 재사용하지 않는다.
- 호버 툴팁은 별도 View/Controller로 구성하고 화면 경계 보정과 포인터 진입/이탈 안정화를 적용한다.
- 현재 `SynergyData`는 3/5 단계이며, 실제 효과는 대체로 해당 직업 계열에 적용된다. `팀 전체 버프`로 바꿀지는 구현 전에 게임 규칙을 확정해야 한다.
- 추천 우선순위: 흑철 전술 명패 → 흑요석 룬 원장 → 귀족 벨벳 교본 → 성유물 스테인드글라스
