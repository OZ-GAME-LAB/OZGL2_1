# 플래티넘 장식 소폭 보강

- 생성 방식: imagegen 정밀 이미지 편집
- 기준: `../Revision05/Rarity_SilverSimplified.png`
- 결과: `Rarity_PlatinumRefined.png`
- 변경 의도: 플래티넘 하단 좌우의 작은 보석과 얇은 이중 테두리로 등급 차이를 보강한다. 큰 장식과 강한 발광은 추가하지 않는다.
- 보존 범위: 실버·골드 디자인, 기존 플래티넘 문장·벨벳, 텍스트와 배치.
- 적용 범위: 레퍼런스 이미지이며 Unity 씬·프리팹·런타임 데이터는 변경하지 않는다.
- 확인: 생성 이미지에서 장식 크기·대칭 및 전체 톤을 1회 육안 확인.

## 생성 프롬프트

정밀 이미지 편집. 첨부 이미지를 정확한 기준으로 사용하여 오른쪽 플래티넘 카드에만 아주 소량의 고급 장식을 추가한다. 전체를 새롭게 디자인하지 않는다.

변경 범위:
1. 플래티넘 카드의 기존 하단 좌우 프레임 모서리 장식 안에 작고 대칭적인 진주빛 백금 보석 포인트를 하나씩 넣는다. 기존 장식에 자연스럽게 통합하며, 카드 너비의 약 1~2% 정도로 아주 작게 한다.
2. 플래티넘 카드 몸체 테두리 안쪽에 가느다란 보조 은백색 선을 추가하여 절제된 이중 테두리로 마감한다. 선은 주 테두리보다 어둡고 얇아야 한다.

반드시 유지:
기존 플래티넘 문장 위의 작은 왕관, 하단 양쪽 각진 날개, 실장식의 크기와 실루엣을 그대로 유지한다. 벨벳의 어두운 와인색과 현재의 은은한 문양을 그대로 유지한다. 큰 문양이나 자수, 추가 날개, 큰 왕관, 큰 보석, 빛 번짐, 발광, 입자, 후광을 추가하지 않는다. 선택 상태처럼 밝게 강조하지 않는다.

왼쪽 실버 카드와 가운데 골드 카드는 픽셀 수준에서 변경하지 않는다. 특히 실버에는 양쪽 실장식이 없는 상태와 수수한 무늬를 그대로 유지한다. 모든 한글 텍스트, 흰색 검 아이콘, 글꼴, 정렬, 여백, 카드 크기, 화면 배경, 제목, 레이아웃을 그대로 유지한다. 기존의 절제된 고딕 도트 UI 스타일과 어두운 전체 톤을 유지한다. 한 장의 전체 화면 수정 레퍼런스를 출력한다.
