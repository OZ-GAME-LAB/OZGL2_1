## 제한 및 팀 연결

시간 초과는 외부 작업의 강제 종료가 아니다. 비협조적인 작업이 끝날 때까지 풀 재사용과 재시작은 차단된다. 실제 팀원 어댑터의 취소/완료 보장이 필요하며, 동기 함수가 메인 스레드를 멈추면 비동기 감시로 해결할 수 없다.

스킬 차단·장판·투사체·실제 증강 UI는 여전히 미연결이며, 새 진단 화면은 그 사실을 표시한다. 실제 스킬 효과를 포함한 전체 전투 검증은 이 결과에 포함하지 않는다. 계정 경험치 지급이나 스테이지 선택 로직도 추가하지 않았다.

정리 오류 결과 저장 검사는 쓰기 가능한 테스트 경로에서 수행했다. 실제 디스크 장애 시 저장을 보장할 수 없으며 StageManager.PersistenceError를 확인해야 한다.

- 로비 이동 요청 상태를 표시 구독자 호출 전에 적용. 구독자의 재실행 요청 차단.
