## 1. 이미 배치한 영역 확장 타일 재배치

- 관찰: 첨부 화면처럼 확장된 영역 사이에 1×1 미확장 칸이 남는 경우가 있다.
- 요청: 이미 배치한 블록 확장 타일도 마우스로 다시 선택하여 위치를 옮길 수 있도록 한다. 사용자는 이를 “마우스 호버로 옮길 수 있도록”이라고 표현했다.
- 제한: 확장 타일은 보관함에 넣을 수 없다.
- 대상: 유닛 배치 발판이 아니라 보드의 사용 가능 영역을 늘리는 확장 타일.
- 확정: 호버 후 드래그, 기존 1×2 묶음 단위 이동, 발판·유닛 제거 후 이동, 초기 영역 고정, 이동 확정 후 전체 영역 연결 유지. 보관은 금지한다.
- 근거 이미지: 사용자 첨부 `codex-clipboard-6c9deb4b-ca91-4baa-9eed-d064d531885f.png`.

## 2. 배치 단계에서 유닛 점유 칸 표시

- 배경: 성급에 따라 유닛의 점유 모양과 칸 수가 달라져, 유닛 이미지 위치만으로 점유 범위를 알아보기 어렵다.
- 요청: 배치 단계에서 이미 유닛이 점유하고 있는 칸 위에 빨간색 표시를 제공한다.
- 표시 기준: 해당 유닛의 현재 성급과 배치 회전을 반영한 실제 점유 칸 전체.
- 목적: 다른 유닛을 배치할 수 없는 점유 영역을 플레이어가 쉽게 식별하도록 한다.
- 확정: 준비 단계에서 상시 옅은 빨간 표시, 잘못된 배치는 진한 빨강과 테두리로 구분한다. 드래그 중인 유닛의 이전 점유 표시는 제외하고 전투 중에는 숨긴다.
- 근거 이미지: 사용자 첨부 `codex-clipboard-65a04ac3-38a0-471a-82c1-faf128099eb4.png`.

## 3. 점유 모양 좌우 반전 및 단축키

- 결정: 기존 R키의 시계 방향 90° 회전을 유지하고, F키에 좌우 반전을 추가한다.
- 목적: 성급 상승으로 생긴 비대칭 점유 모양을 회전만으로 맞출 수 없는 공간에도 배치할 수 있도록 한다.
- 조작: 드래그 중 F키를 누르면 점유 모양과 고스트 미리보기를 함께 반전한다. 다시 누르면 원래 모양으로 돌아온다. 좌우 대칭 모양은 모양 변화가 없다.
- 상하 반전 전용 단축키는 추가하지 않는다. 좌우 반전과 180° 회전 조합으로 표현한다.
- 반전 대상은 점유 모양이며, 유닛 외형 및 공격 방향과 분리한다. 점유 칸 수는 유지하고 기존 겹침·영역·발판 조건을 동일하게 검사한다.
- 후속 구현 시 미리보기, 배치 확정, 재배치, 합성, 전투 전달 데이터에 반전 상태가 일관되게 반영되어야 한다.
- 화면 조작 안내: `R: 회전 · F: 좌우 반전`.
- 상태: 구현 및 검증 완료. F는 현재 화면 기준 좌우 반전이며, 보관·재배치·합성 대상·전투 전달 데이터에 반전 상태를 유지한다.

- 쉬움 난이도 30라운드 클리어 확인.

- 확인 주체: 사용자 직접 플레이 테스트 보고.
