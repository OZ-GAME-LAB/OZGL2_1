# GridManager 2차 피드백 구현 검증 — 2026-09-11

브랜치: feat/grid-manager/14. Unity 6000.3.22f1.

## 변경
- 유닛은 독립적인 점유 모양/좌표/회전을 사용하며 발판당 1기 및 모양 일치 제한 제거.
- 발판 하나의 여러 유닛, 여러 발판에 걸친 유닛 지원.
- 공용 보관함 최대 10개. 기본 초기 지급은 유닛 1기+발판 1개. 확장 보상은 보관함과 별도.
- 유닛 우선 선택, 빈 발판 선택, 두 종류의 공용 보관함 드롭 회수.
- 공간 부족 시 기존 항목 선택 폐기와 보상/회수를 원자적으로 적용. 취소/중복/이전 요청 방어.
- 보상/회수 대기와 배치 상태는 씬 재진입에도 세션에서 유지.
- SO 참조 및 배치 스냅샷을 새 규격으로 갱신. 원본 SO GUID 유지.

## 수행한 검증
- GridVerification PASS: 6종 모양과 회전, 칸 점유/교차 발판, 복수 유닛, 중복 점유 거절, 스냅샷 불변, 한도 10, 원자적 폐기/지급/복수 회수, 이동 대기 취소, 오래된/다른 실행 요청 거부, 중복 선택 거부, 관찰자 재진입 차단, 14회 확장.
- GridPlayVerification PASS: UI Toolkit 포인터/키 입력, 유닛 우선 선택(비기준 칸 포함), 두 종류 회전과 공용 보관함 회수, 초록/빨강 고스트, 실패 복원, 전투 입력 잠금, 필수 확장.
- GridSessionPlayVerification PASS: 반복 보상과 한도 유지, 폐기 선택 UI/확정, 보상 및 회수 대기 중 실제 씬 재로드, 취소 원상 보존, 외부 세션 주입 및 종료.
- 추가 UI 취소 확인: 미수령 보상과 기존 10개 항목 보존.
- 공간 확보 화면 캡처로 레이아웃 확인. 항목명 줄바꿈/툴팁 및 선택 시 스크롤 위치 유지.
- Console 오류/경고 0건. 신규 스크립트 .meta 생성 확인. 변경 C#/Markdown diff 검사 통과.

## 제한 및 인계
- 자동화 UI 이벤트와 화면 캡처로 검증했다. OS 마우스/다양한 해상도의 수동 QA, 빌드는 수행하지 않았다.
- 실제 Stage/전투/합성/시너지/영구 저장 연결은 변경하지 않았다. 단일 BlockId를 제거한 스냅샷 규격과 보상 공간 확보 대기를 연결 담당이 반영해야 한다.
- 작업 파일은 Grid 코드/더미 SO/검증 및 공유 문서에 한정. 씬·프리팹·프로젝트 설정·외부 에셋 변경 없음.
- 커밋/푸시/병합은 하지 않았다.
